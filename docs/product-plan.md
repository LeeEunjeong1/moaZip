# moaZip Product Plan

## Concept

moaZip is a household asset dashboard for newly married couples and families.
The app focuses on seeing the big picture: how much money the household has
saved, how investments are performing, and how close the couple is to a future
home purchase.

The product is designed for monthly or quarterly updates instead of daily
transaction logging.

## Positioning

moaZip is not a spending diary. It is a household asset status board.

The main emotional hook is:

> How much did our household assets grow this quarter?

## Primary Users

- Newly married couples
- Couples saving for a home
- Families who manage shared and individual assets together

## Key Use Cases

1. Update current asset amounts from Android.
2. Import an XLSX file to update many assets at once.
3. Review quarterly growth in net worth.
4. Track investments with current amount, principal, profit/loss, and return.
5. Track recurring savings and expected balances.
6. View a web dashboard on a PC or Mac.

## Android Screens

### Home Dashboard

- Net worth
- Household asset growth since previous quarter
- Financial assets
- Investment profit/loss
- Monthly savings
- Home purchase goal progress

### Asset List

- Owner filter: joint, Eunjeong, Jaewoong
- Type filter: asset, investment, liability
- Category filter: savings, retirement, subscription, cash, deposit, loan, ISA, stock, dividend

### Asset Edit

- Current amount
- Principal
- Quantity
- Memo
- Status

### Recurring Savings

- Monthly amount
- Start date
- End date
- Payment day
- Expected current amount
- Linked asset

### Excel Import

- Download moaZip XLSX template
- Pick XLSX file
- Preview parsed rows
- Add new assets
- Update existing assets
- Save quarterly snapshot

## Web Screens

MVP web is read-first.

- Login
- Dashboard
- Asset list
- Asset distribution charts
- Quarterly net worth trend
- Excel import status and history

## MVP Exclusions

- Bank or card auto-linking
- Open banking APIs
- MyData integration
- Complex spending analysis
- Automatic stock price sync
- Fine-grained family permissions
